Persian Captcha

Every challenge the service can hand out, one widget each, with the server-side verification round trip behind each button. The site keys are declared in captcha.demo.yaml; each is pinned to a single challenge kind, which is what makes this page predictable and is not something a real site should copy.

      /submit, which exchanges the token at
      POST /v1/siteverify using that card's secret and prints the
      reply verbatim. A token is single use, so the widget is reset afterwards.
